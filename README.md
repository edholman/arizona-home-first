# Arizona Home First

Lead generation website for Arizona homebuyers. Helps connect homebuyers with licensed lenders and realtors who offer credits toward closing costs.

## Features
- Interactive eligibility quiz
- Automated email drip campaigns (24 months)
- Twilio call integration
- GoHighLevel/LeadConnector webhook
- SendGrid email notifications
- Admin dashboard

## Tech Stack
- React + TypeScript (Vite)
- Express.js backend
- PostgreSQL (Drizzle ORM)
- Tailwind CSS + shadcn/ui
